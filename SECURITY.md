# Security policy

## Reporting a vulnerability

Report it privately on GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. Please do not open a public issue.

You will get a first answer within three working days. The fix ships as a patch release, and a GitHub security advisory is published together with it.

## Supported versions

| Version | Supported |
| --- | --- |
| The latest 0.x minor release | Yes |
| Older releases | No |
